Clinical pediatric growth assessment utility built to calculate and visualize **World Health Organization (WHO) Anthro Z-scores** and percentiles for infant and child development metrics.

---

## 🎯 Clinical Application
Pediatric evaluation relies on standardized Z-score deviations to diagnose nutritional and growth conditions:
- **Weight-for-age**
- **Length/height-for-age**
- **Weight-for-length/height**
- **BMI-for-age**

This tool executes mathematical interpolation against standard WHO LMS (Box-Cox transformation, Median, Generalized Coefficient of Variation) reference tables.

---

## 🛠️ Tech Highlights
- Pure, fast mathematical calculations with zero heavy external runtime dependencies.
- Modular JavaScript architecture easily embeddable into larger hospital or clinical EHR systems.
- Intuitive interface for immediate clinical data entry.
